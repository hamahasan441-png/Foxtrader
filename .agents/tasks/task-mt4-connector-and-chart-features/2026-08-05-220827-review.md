## v2 fix verification: bar-mode transform tests

`HeikinAshiTransformerTest` validates four cases: empty input returns empty, a single candle computes HA Close as `(O+H+L+C)/4` with HA Open equal to the standard open, multi-candle chaining derives HA Open from `(prevHaOpen + prevHaClose) / 2` (verified with `expectedHaOpen1 = 100.625`), and timestamps pass through unchanged.

`CandleRenkoBuilderTest` covers six cases: the three guard-clause paths (`empty`, `brickSize <= 0` producing empty output), a single candle that doesn't move enough for a brick, bullish multi-brick generation (two bricks from a 20-point move with `brickSize=10`), bearish multi-brick generation (two bricks from a 20-point drop), and volume accumulation spanning three candles where only the third triggers a brick (asserting `volume = 600.0` as the sum of all three). The volume-resets-after-brick-emit detail is verified in the bullish test where the second brick from the same candle carries `volume = 0.0`.

## v2 fix verification: disconnect clears persisted accountId

```kotlin
override suspend fun disconnect() {
    quoteStream.disconnect()
    accountId = ""
    appPreferences.setMetaApiAccountId(null)
}
```

The `connect()` path's conditional check (`!cachedId.isNullOrBlank()`) will now correctly fall through to `deployAccount()` after a disconnect, preventing stale-account reuse across broker/server changes.
